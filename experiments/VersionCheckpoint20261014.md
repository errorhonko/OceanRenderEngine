- 136 个文件迁入实体模块目录，主工程筛选器对应目录，统一模块限定 include。
- 通用网格/BVH 与海面分离；模拟接收、ADC、数字处理、扫描及点云输出分别归类。

- 累积提交多回波提取/选择、通用扫描计划、旋转多线、平台轨迹、多帧扫描及 PCD 输出。
- 累积提交 OBJ/MTL 解析、单位/坐标转换、场景组装、逐面材质绑定、光谱反射率与 Lambert/粗糙导体接口。
- 纳入既有 DX12 计算与持久单三角形 DXR 基础模块及其硬件验收，不宣称完整 GPU 渲染器。
- 六个 CPU/GPU/实验工程固定 Windows SDK 10.0.26100.0，UTF-8 编译设置与默认清单生成正常。
- README、目录迁移清单、材质方案及 SDK 验证记录同步。

## 发布范围

提交源码、工程、合成 fixtures、依赖许可和实验/获取脚本；不上传构建输出、SDK DLL、
本地备份或 HELIOS 下载模型。外部场景资产通过固定 commit 的脚本另行获取；缺失时外部验收会 SKIP，
因此新克隆的检查总数可能少于本机完整结果。无需网络的普通确定性测试仍可运行。

本次属于 checkpoint 提交，不创建发行包或声称生产就绪。
