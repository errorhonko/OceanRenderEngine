# 海面法线线性化数值实验

独立控制台程序，不修改渲染器、BRDF 或正式验收测试入口。比较高度叠加模型下的精确法线和一阶坡度转换；不是物理实测验证，也不是回波误差估计。

## Visual Studio 使用

通过“添加 → 现有项目”选择本目录 `OceanNormalStudy.vcxproj`，设为启动项目，选择 Release/x64。项目属性 → 调试 → 命令参数填入：

```
study-100k-seed42.csv 100000 42
```

输出相对路径以调试工作目录为准。程序拒绝覆盖已存在的文件。仅运行确定性检查时参数填 `--self-test`。需要 C++20、v145 工具集。

## 计算与采样测度

长波坡度为 (p,q)，高斯短波坡度为 (dp,dq)，精确法线为 normalize(-p-dp,1,-q-dq)。一阶法线由局部坡度 J(dp,dq) 还原。内部几何使用 double，局部坐标系遵循生产代码投影世界 X 的约定，并校验其协方差与 OceanNormalDistribution 一致。

通过相关高斯采样得到短波坡度，每个样本等权，代表**世界水平投影面积测度**。精确和近似使用同一批样本，所有参数组也复用标准正态样本。使用 mt19937_64 和显式 Box-Muller，固定 seed 可在同一构建下复现；跨平台数学库可能有末位差异。

方向锥概率是上述测度下的指示函数均值，不是局部投影面积 NDF、可见法线 PDF 或 BRDF。不乘 Fresnel、遮蔽或面积转换权重。不能把概率差直接解释为回波能量差。

## 当前扫描

- ElfouhailyConfig 默认海况：U10=10 m/s、u*=0.38 m/s、逆波龄 0.84、风向世界 +X。并非现场实测海况。
- kc 为 1、4、16 rad/m；kmax 固定 10000 rad/m，以上尾部未积分。独立实验不实例化高度场，这些 kc 是显式扫描值，不声称来自当前网格。
- 积分使用 512 径向、128 角向样本。
- 长波倾角 0、15、30、45、60、75、80 度；水平坡度方位角相对世界 +X 为 0、45、90 度。
- 5 个诊断方向锥：宏观法线方向，以及局部极角 10 度、方位角 0/90/180/270 度；半角均为 2 度。它们不是指定接收器的实际方向。

共 63 组，每组 5 行 CSV。修改 main.cpp 中扫描列表可增加范围。复现时同时保存源码版本、构建配置和 CSV。

## 输出与解释

CSV 保存海况、积分范围、协方差、角度、样本数、seed，及：

- epsilon_rms：分母扰动的解析 RMS，不是角度或能量误差界。
- angle_mean/p50/p95/p99/max_deg：精确和近似单位法线夹角，包含下半球样本；最大值依赖样本数。
- lower_fraction：精确法线相对长波局部法线点积 <=0 的比例。未剔除、未重新归一化。
- lower_se：二项比例的插入式标准误；零次事件时输出 0 **不意味着真实概率为零**，95% 单侧概率上限可粗略用 3/N 判断。
- cone_exact/linear：方向锥概率。
- cone_delta：linear - exact，绝对概率差，不是相对百分比。
- cone_delta_paired_se：由成对指示函数差计算的均值标准误；稀有事件或零次差异时不能据此断言无误差。

建议先运行 100000/42，再运行 1000000/42 和 100000/43。比较分位数与概率差的稳定性；参数组因共用样本而相关。若方向锥事件太少，增加样本数。后续分别改变积分精度、积分上限，避免把统计噪声或谱截断与坐标线性化混为一谈。

## 确定性检查

平面精确一致；垂直长波倾斜方向的扰动精确一致；45 度/0.2 坡度例子的约 0.516164 度误差；精确分式恒等式；越过局部切平面后法线比较仍有限；double 参考协方差与生产实现一致。

精确局部坡度在切平面附近可能发散，因此不使用它的样本方差作为主要指标。不自动为生产模型设定误差合格阈值。

## 首轮验证记录（2026-09-26）

Release/x64 编译通过；本程序 6 项确定性检查通过；原有项目 360 项验收检查通过。固定 seed=42、N=100000 重复运行 CSV 哈希一致。编译沿用本机命令行参数 `/p:GenerateManifest=false`，没有修改项目全局清单设置。公共 BRDFUtils.h 存在原有浮点常量截断警告。

默认海况，kc=4 rad/m，长波倾角 30 度、水平坡度方位角 0 度：

| 样本数 | seed | 夹角中位数/度 | 95% 分位数/度 | 99% 分位数/度 |
| --- | --- | --- | --- | --- |
| 100000 | 42 | 0.303950 | 1.747324 | 2.823740 |
| 1000000 | 42 | 0.303845 | 1.754072 | 2.878567 |
| 100000 | 43 | 0.307479 | 1.754801 | 2.865557 |

这只是初步稳定性对照，不是所有参数的收敛证明。在百万样本扫描中，kc=4、倾角45度、坡度方位0度、诊断锥局部极角10度/方位180度时，精确锥概率0.003734、线性概率0.006469，绝对差0.002735，成对标准误约0.00007147。表明某些方向的概率差可明显超过采样噪声，但仍不是 BRDF 或回波误差。
