## 程序做什么

1. 生成冻结的实值高斯短波高度场。每对正负模式满足 H(-k)=conj(H(k))，E|H(k)|²=Psi(k) DeltaK²，IFFT后恢复N²归一化。当前Elfouhaily输入采用两侧PSD的偶对称部分。
2. 模式由有符号频率整数和seed共同确定，固定L、频带与seed时改变N可保留同一组连续波模态；只会改变离散网格/IFFT舍入。改变L则改变频率格点，不能声称仍为同一个实现。
3. 构造有限三角网格，计算每个三角形的几何法线；不使用光滑顶点法线作为遮挡参考。
4. 使用生产BVH，实验专用StudyTriangle以double计算相交，并采用与三角形尺度相关的平行判定。没有修改生产MeshTriangle。只有显式运行时才会先执行平面、小三角形和自相交基础检查。
5. 按水平面积均匀采样位置、向观察方向发射射线；每个正向法线样本按微表面面积权重1/m.y统计。条件法线组内的可见率为sum(weight*V)/sum(weight)，是比率估计量，不保证有限样本无偏。
6. 与同一离散谱的集合坡度协方差给出的Smith候选比较，而不是未经匹配的连续谱积分。另用当前三角网格测得的坡度方差给出诊断预测，后者不能作为独立理论验证。

冻结快照使用已有默认重力9.81、密度1000、表面张力0.074配置；没有色散时间演化。相邻样本空间相关，不能把所有点都当成独立伯努利样本。

## 边界与未判定样本

有限FFT海面隐含周期模型。本程序不直接把离开网格、或到达追踪距离上限判作可见：

- 射线命中其他三角形：Blocked。
- 无命中且终点高于本周期网格的全局最高点：Clear。由于光线朝上、周期三角面不会高于其最高顶点，对该网格的周期延拓可证明后续不再命中。
- 否则：Censored（未判定）。

输出可见率下界Clear/Total，以及上界(Clear+Censored)/Total（均按面积加权）。不丢弃未判定样本后重新归一化。这个证据只针对生成网格的周期延拓，不证明真实无限随机海面最高点也受此界限制。增大区域、降低周期伪相关和加长追踪范围仍需要验证。

## 输出文件

输出目录必须不存在，程序拒绝覆盖旧目录。目录中含：

- parameters.txt：参数、测度、范围，开始时status=started，全部CSV成功关闭后status=completed。
- surface_diagnostics.csv：离散谱集合坡度协方差、当前傅里叶实现的坡度二阶矩、网格几何坡度二阶矩、虚部残差和最高高度。区分随机实现变化与网格低通误差。
- visibility_by_seed.csv：每个seed/观察方向/法线分组的计数、面积权重、可见率上下界、未判定面积比例、Smith预测和偏差区间。包含全部正向面和同站半程法线方向锥诊断。
- summary.csv：跨非空seed的比率均值和seed间标准误；**不是独立表面点的二项置信区间**。这是探索性摘要；分组稀疏时，省略空seed会带来选择效应，必须先看nonempty_seeds及逐seed计数，不能将该均值当作可靠总体估计。不同观察方向共享样本、不同分组也不是独立实验。

空组输出nan，不伪装成零可见率。每seed组内少于100个正向样本或不是全部seed都非空时，建议标记为稀疏组，不据其判断Smith失效。大观察角对应的同站半程法线可能极罕见，这是重要的采样不足提示。

## 编译与安全运行入口

Visual Studio添加现有项目OceanVisibilityStudy.vcxproj，选择Release/x64。不传参数仅打印计划；不会生成海面或文件。只有显式传入 `--run 新目录` 才执行运行时自检和完整实验。

首轮参数示例（**尚未执行**）：

```text
--run visibility-pilot
```

更小的流程试跑（只能检查运行流程，不足以形成统计结论）：

```text
--run visibility-smoke --seeds 2 --samples 2000
```

可调选项：

```text
--resolution 256 --samples 20000 --seeds 8 --first-seed 42
--length 4 --k-min 8 --k-max 32 --max-distance 1 --offset 0.000001
--observation-length 1
```

新增窗口参数单位m；默认0保持原来的L/4中心方形窗口。显式正值必须小于L。区域对照时用相同显式窗口，避免L变化同时改变观测范围。v2运行参数文件记录实际窗口边长。

当前限制N为32…1024的2次幂，最短波至少8个网格间隔、频带在Nyquist内。观察方向和法线组宽在源码明确列出，第一版不做自动多组扫描。编译检查沿用本机 `/p:GenerateManifest=false`，未修改清单配置。

## 后续收敛计划（须另行确认，不自动执行）

1. 同seed、L和频带，将N从256改为512；三角形变为524288。先检查几何坡度矩与同一傅里叶实现坡度矩的差。
2. 改变offset（例如3e-7、1e-6、3e-6 m），检查近邻遮挡对偏移是否敏感。float射线起点/方向仍限制数值精度，double三角求交不等于全流程double。
3. 扩大L同时保持网格间隔与频带，比较多个新实现；适当增加max-distance，观察Censored是否下降。
4. 增加独立海面数，检查法线组的统计稳定性；优先看实际收发相关的法线，不只看all_front。
5. 最后才扩展频带、倾斜宏观面和G2。不进行回波计算、Fresnel加权或BRDF能量验证。
