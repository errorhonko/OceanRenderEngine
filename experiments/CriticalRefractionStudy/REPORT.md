# 极临界角折射误差：固定样本对照

2026-10-16。前半为修改前的独立诊断；末尾记录随后落地的局部混合精度实现。
结论针对下述参数和记录，不是所有材质的误差上界，也不是整体回波误差。

## 结论

原先约 1.07% 的 Sample_f.f / f(wo,wi) 差异已精确重放。
它不是单一 Fresnel 公式或“方向最后存成 float”导致：
微小单位长度残差、折射率倒数舍入、点积及 Snell 运算误差，先改变折射方向；
低精度法线反演和临界 Fresnel 再放大差异。
仅换 PBRT 风格正弦平方公式或仅对 Fresnel 使用 FMA，不能消除整条链的误差。

## 固定配置与重放

- eta=1.5，alphaX=.6f、alphaY=.85f，seed=42，131072 次条件透射试验。
- wo 使用现有 NormalizeDirection(.8f,.1f,-.6f)，实际 float 值为
  (.7960297465324402, .09950371831655502, -.597022294998169)。
- 全批次成功 50024 次；12 个样本满足重建微表面透射余弦绝对值 <.02。
- 原来最坏的样本编号为 86831（从 0 开始）。
- 重放使用现有 RandomStream、VNDF、Refract、DielectricBxDF；
  逐个核对折射方向位值，以及实验公式与正式 Sample_f 的值。
  全部成功样本的 float 散射值重放最大相对差为 **0**。
- 导出全部临界样本、差异 >=1e-4 的样本，以及 index%2048==0 的普通对照，
  共 49 个样本。此集合有意偏向异常，不用于估计整体平均误差或能量。

## 对照结果

表中都是原来最坏样本的“两条求值路径相对差”，定义为
abs(f_sample-f_query)/max(abs(f_sample),abs(f_query))，不是对物理真值的误差。
后几行固定同一个微表面，不重新随机采另一个法线。

| 处理路径 | 两次散射值相对差 |
| --- | ---: |
| 正式旧 float 路径 | 1.070733% |
| 只替换成 PBRT 风格的 float Fresnel（正弦平方、相对 eta 参数） | .886893% |
| 只对 float Fresnel 使用 FMA 实验式，其余不变 | .603500% |
| 将旧方向转成 double，归一化后重新求值/重建法线 | .626397% |
| 先归一化，再用 double 重算折射；最后仅把 wi 存成 float | .000133220% |
| 同上但 wi 保持 double，不回存 float | 约 2.3374e-9% |

最后一项的无百分号相对值为 2.3374e-11。
对全部 12 个临界样本，double 重新折射并保持方向精度的最大相对差同为 2.3374e-11；
仅在最后将 wi 存成 float 的最大相对差为 2.9335e-6（.00029335%）。

FMA 项只改了 Fresnel 内部运算，不能据此推断完整向量 FMA 实现的结果。
PBRT 风格项是独立实验公式，不是运行了 PBRT 可执行程序；它同时采用相对 eta
参数化，包含倒数舍入差异，不将结果归因于“少一个 sqrt”这一单因素。

## 误差具体来自哪里

### 1. 透射量主导这次 f 的差异

原样本 f_sample=.00018734106561169028、f_query=.00018533514230512083 sr^-1。
将 f 写成 T × K（T=1-R，K 为其余因子），得到：

- T_query / T_sample = .9892854407597458。
- K_query / K_sample = 1.0000073037899302。

因此此例的两路 f 差异主要集中在透射量 T，而不是 D/G 或其他乘法因子。
但 T 的输入误差来自上游方向计算与法线重建，不能等同于“Fresnel 函数单独有错”。

### 2. Snell 根号内量 q 的逐项分解

定义 q=1-sin^2(theta_t)。以相同 float 位值的 wo、wm 为输入，
先用高精度把它们归一化，得到单位方向基准；再逐步恢复旧计算链：

| 阶段 | q |
| --- | ---: |
| 高精度单位方向、精确 eta=2/3 | .0000164201378665006 |
| 不修正原 float 向量的长度残差 | .0000164695232603971 |
| 再将 eta 改为 float 保存的 1/1.5f | .0000165291269208479 |
| 再使用 float 点积结果 | .0000165564482327656 |
| 再使用旧 float 平方/除法/相减 | .0000166296958923340 |

四个逐项增量分别约为：

- 单位长度残差：+4.93854e-8。
- eta 倒数舍入：+5.96037e-8。
- 点积舍入：+2.73213e-8。
- 其余 Snell 运算：+7.32477e-8。

增量可望远镜求和，已验证闭合。它们合计约为基准 q 的 1.28%，
但不能把这四项的占比直接当作最终 f 或回波误差占比：顺序与非线性传播很重要。

原 float 向量的长度平方：
wo = .999999968048202，wm = 1.000000071459596。
这些约 1e-8 量级的误差在普通角度很小，在 q 接近零时却足以产生影响。

### 3. float 法线重建还会改变输入

对旧方向按高精度归一化后，入射方向与微表面法线的点积（此例带符号为负）为：

- 原微表面：-.7453608880231155。
- double/高精度重建微表面，精确 eta：-.7453609505540448。
- 高精度重建但用 float eta：-.7453609327187336。
- 旧 float 重建法线再高精度归一化：-.7453608726688855。
- 正式 f() 的 float 点积：-.7453608512878418。

差异虽只在末几位，临界透射却对这些末位敏感。

## 高精度参考到底是什么

Analyze.py 使用 Python 标准库 Decimal，未安装新数值库：

1. 用 Decimal.from_float 恢复输出数字对应的精确二进制浮点值。
2. 对方向做高精度单位化，使用精确 eta=3/2、2/3。
3. 使用独立 Cartesian GGX D、Smith G、Snell 和非偏振 Fresnel 公式。
4. 用功率透射的有理式计算 T，避免在参考中用低精度 1-R 相减。
5. 所有 12 个临界样本比较 80 位与 120 位参考；相关散射值最大相对差约 2.77e-75。

已存 float 方向对的高精度 BTDF 参考为 .00018767963321285858 sr^-1；
原采样返回值相对该参考差约 .1804%，原 f() 查询值相对该参考差约 1.2492%。
这里方向被解释为单位方向，并不把未经单位化的 float 代数结果当物理真值。

另一个参考值 .00018532466205481081 对应“保持同一微表面、重新准确折射”的新方向，
它与旧保存方向不是同一个方向对，因此不将二者数值差直接称为算法误差。

## 极限扫描：不能从错误输入恢复信息

单独取界面法线为 +Z，扫描 q_target=±10^-2 到 ±10^-14。
在正侧 q_target=10^-9..10^-14 的 6 个点，入射余弦一旦量化为 float，
其高精度参考 q 已变成约 -9.65745e-8，即落到 TIR 另一侧。
三个 float 公式在这些已量化的输入上均与对应参考保持相同分类。

因此这组翻转不是“Fresnel 在同一输入上判错了”，而是输入量化改变了物理角度。
FMA/后置 double 无法恢复已丢失的入射方向信息。这是极限压力测试，
不表示已重放的 12 个真实样本发生了同样的分类翻转。

## 原诊断后的建议（现已落实，见下一节）

先实验局部混合精度：关键向量单位化、点积、Snell、eta 倒数与法线重建使用 double，
尽可能最后才回存 float；Fresnel 使用一致的角度量与稳定公式。
保存当前实验作回归，不通过加大 MC 样本数或钳制 f/PDF 掩盖数值误差。
仍需检验多个角度/seed、性能和传输权重，不能直接承诺整个回波也达到表中误差。

参考：[PBRT scattering.h](https://github.com/mmp/pbrt-v4/blob/master/src/pbrt/util/scattering.h)、
[PBRT 数值工具](https://github.com/mmp/pbrt-v4/blob/master/src/pbrt/util/math.h)。
