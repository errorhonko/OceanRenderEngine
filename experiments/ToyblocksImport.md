# Toyblocks 完整导入与三帧扫描验收

2026-10-13。使用 HELIOS++ 官方仓库固定版本
`2b3585aa766213ae9a46c4790ad4f3594ffa213d` 的真实 OBJ/MTL。
[原始场景 XML](https://github.com/3dgeo-heidelberg/helios/blob/2b3585aa766213ae9a46c4790ad4f3594ffa213d/data/scenes/toyblocks/toyblocks_scene.xml)
仅作来源参考；本实验不执行 HELIOS++ XML，不声称复现其原始 survey 或输出。

## 验收链路

`OBJ + MTL → ObjMeshLoader::Read → Convert → 测试尺寸/位置调整 → SceneBuilder → 网格 BVH + 场景 BVH → LidarScanDriver / LidarMultiFrameDriver → 光学回波 → 接收电路 → ADC → 重心测距/固定延迟校正 → 点云 → PCD`

几何命中的真实距离仅用于结果评价，未用于直接生成点的距离。
所有模型使用统一的 `LambertianLidarScattering(0.5)`；读取 MTL 不等于实现
HELIOS++ 的 `helios_spectra`、木材光谱或逐材质雷达反射率映射。

## 输入与布局

源数据按 1 metre/unit 假定，从 Z-up 变为引擎 Y-up：`(x,y,z) → (x,z,-y)`。
原始 OBJ 文件不修改。导入后在实验辅助函数中按包围盒水平居中、最低点落地，
再做正数等比缩放和世界平移。这是测试模型的尺寸调整，不是单位换算。

| 物体 | 原始三角形 | 测试缩放 | 落地中心位置/m |
|---|---:|---:|---|
| groundplane | 2 | 20 | (0,0,0)，40×40 m |
| 前方 cube | 12 | 0.1 | (0,0,8)，约 2 m 尺寸 |
| 后方 cube（复用模型） | 12 | 0.1 | (0,0,13) |
| sphere | 960 | 0.05 | (-4,0,10)，约 2 m 直径 |
| cylinder | 124 | 0.1 | (4,0,10)，约 2 m 尺寸 |

共 5 个场景对象、1110 个三角形。源模型并非理想轴对齐数学图元，保留其原始形状。

## 扫描与接收参数

- 六线旋转：俯仰角 -20°、-10°、-3°、0°、3°、10°；64 列/圈，10 Hz。
- 每帧 384 个脉冲，三帧起点为 1.0、1.1、1.2 s。
- 平台从 t=1 s 的 (-0.5,1.5,0) 匀速移到 t=1.3 s 的 (0.5,1.5,0)，朝 +Z、上方 +Y；按各脉冲发射时刻求位姿。
- Delta 空间光束、1 ray/pulse；532 nm、10 nJ，GaussianPulseProfile(4 ns) 时间轮廓，4 ns 为 FWHM。
- 接收孔径 0.01 m²、光学效率 0.8、视场半角 0.02 rad；量子效率 0.6。
- 一阶响应时间常数 2 ns，跨阻增益 10000 V/A；零电压噪声、16-bit ADC，量程 [-1,1] V。
- 波形 2048 箱、箱宽 0.25 ns；噪声窗口 [0,10) ns，搜索窗口 [10,450) ns，均相对发射时间。
- 单回波全搜索窗口重心测距，固定扣除 2 ns 响应延迟；拒绝削顶；seed 42/43。

这是低噪声、窄光束的端到端接入基线，不是多回波、强噪声或高斯光斑压力测试。

## 检查内容和实测结果

专项测试 43 项通过；CPU 全量回归 Debug / Release 各 1940 项通过，无失败、无跳过。
专项覆盖四个真实资源的 OBJ/MTL 读取、三角形数量、尺寸、组装，
定向扫描命中球/柱/立方体、前后遮挡与天空漏射，以及完整三帧的脉冲数量、
命中/测量关联、削顶诊断、测距误差、逐点传感器坐标、PCD 坐标/行数、
跨帧 ID 唯一性、位姿移动和固定 seed 的整帧字节一致重放。

| 帧 | 发射数 | 几何命中/测得点 | 未命中 | 平均绝对测距误差/mm | 最大绝对误差/mm |
|---|---:|---:|---:|---:|---:|
| 0 | 384 | 148 | 236 | 1.932 | 3.661 |
| 1 | 384 | 141 | 243 | 1.994 | 3.661 |
| 2 | 384 | 148 | 236 | 1.939 | 3.661 |

三帧均无 ADC 越界。误差对照的是同一导入三角网格的中心射线距离，不是解析球面真值。
验收上界为最大误差 <15 cm、平均绝对误差 <5 cm；表中的毫米级结果只是本配置实测，
不是仪器精度承诺，也不代表 0.25 ns 分箱能普遍提供毫米分辨率。

## 复现与输出

1. 在仓库根目录运行 `models/helios_toyblocks/FetchToyblocks.ps1`：固定版本下载、SHA-256 验证；遇到本地不同版本不覆盖。
2. 构建并运行 Visual Studio 的 CPU `OceanRenderEngine.Tests`，包含此专项验收。缺资源时显式 SKIP，不计为通过。
3. 若要导出，打开 Visual Studio **x64 Native Tools** 终端，进入仓库，启动允许本地脚本的 PowerShell 7 会话并运行：

```powershell
pwsh -NoProfile -File .\experiments\ToyblocksImport\Run.ps1
```

默认输出到 Git 忽略的 `out/ToyblocksImport/run-...`。可用 `-OutputDirectory` 指定新目录。
实验独立入口不修改项目 `main.cpp`，只链接专项测试和 tinyobj 实现。
本机旧版 Windows PowerShell 拦截了新脚本；已用 PowerShell 7 成功编译、验收并导出，未修改系统执行策略。

输出六个 PCD：三帧各一份世界坐标、一份逐点发射时刻传感器坐标；另有 `summary.txt`
和 `ground_truth_frame_poses.txt`（帧起点真实位姿，不是估计轨迹）。
世界点云适合检查几何/轨迹；传感器点云可作为后续 SLAM 原始输入，保留帧内运动，
尚未转换到 ROS 等系统的坐标约定。姿态真值不应泄漏进 SLAM 估计输入。

## 范围与下一步

目前验证了真实文件导入到扫描输出的完整链路；不是已接入 SLAM，也不是具有充分约束的 SLAM 数据集。
只有 64 方位列、简单地面和少量图元，后续应提高采样密度、延长轨迹、加入有墙面/结构的场景，
再验证光束足迹、多回波、噪声与材质映射。SLAM 前还需要逐点时间、约定坐标变换和轨迹评价流程。
