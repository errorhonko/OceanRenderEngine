# Urban：同位姿视觉与 LiDAR 阶段验收

2026-10-19。使用本引擎重跑 HELIOS++ Urban 静态资产，显式启用
`TerrainContact`。RGB 和雷达共享位置、朝向和场景放置；这不是运行上游
HELIOS survey，也不是新增通用相机框架或 SLAM 系统。

## 运行

Windows x64，VS v145，Windows SDK **10.0.26100.0**，PowerShell **7+**。
Python 需 numpy、Pillow；绘图默认使用 Windows 的微软雅黑字体。
先自行检查并获取资源，脚本不隐式下载：

```powershell
.\models\helios_urban_static\FetchUrbanStatic.ps1
.\data\materials\spectra\helios\FetchHeliosSpectra.ps1
```

在已初始化 SDK 10.0.26100.0 的 VS x64 Developer PowerShell 7 中，从仓库根运行：

```powershell
.\experiments\UrbanSensorCheckpoint\Run.ps1 -PythonPath python
```

若使用传统 VS 命令提示符，先通过 VsDevCmd 的 `-arch=x64 -host_arch=x64
-winsdk=10.0.26100.0` 初始化，再调用 `pwsh -File` 运行脚本。
`-OutputDirectory` 可指定**尚不存在**的目录；`-RepositoryRoot` 通常无需设置。
失败时保留部分输出和日志，重新运行应选择新目录，不删除或覆盖旧结果。

运行顺序：

1. 编译独立 `Scan.cpp` 和 `Render.cpp`，链接现有 tinyobj 实现。
2. 导入场景并扫描一周，走现有回波、波形、模拟接收、ADC、测距链路。
3. 从本次世界坐标 PCD 的 VIEWPOINT 恢复相机位姿，重新导入相同布局并渲染。
4. 投影本次测距点，独立核对内外参、线性图像和序列化范围。
5. 输出图像、聚合指标、源文件 SHA-256。主程序入口、引擎类和普通 Camera 不变。

## 固定参数

| 项 | 本次配置 |
| --- | --- |
| 资产版本 | HELIOS++ `2b3585aa766213ae9a46c4790ad4f3594ffa213d` |
| 几何 | 27 个独立 OBJ、42 个放置部件、53 个网格、2,445,341 个有效三角形 |
| 场景时刻 | 冻结动态车；静态场景、静止平台 |
| 坐标 | 世界 Y-up、米；传感器 X-right / Y-up / Z-forward |
| 共享位置 | `(0, 8.8, -70)` m，前向 +Z、上向 +Y；道路 Y=7 m |
| 时间 | 雷达帧 `[1,1.1)` s；相机快照 1 s；场景无运动 |
| 雷达扫描 | 16 线，仰角 -25° 至 +15°；720 方位，0.5° 间隔，10 Hz |
| 发射 | 905 nm、10 nJ；高斯方向模型 1/e² 半角 0.15 mrad、截断 0.45 mrad |
| 光束积分 | 每脉冲 16 条射线，4×4 二维分层；ray seed 42、noise seed 43 |
| 接收 | 口径 0.002 m²、效率 0.8、视场半角 2 mrad、量子效率 0.6 |
| 脉冲与模拟链 | FWHM 4 ns、一阶响应 tau=2 ns、跨阻 10000 V/A；电压噪声为 0 |
| 数字化 | 16-bit ADC，[-1,+1] V；4096 箱×0.5 ns，起点 -20 ns |
| 检测 | 噪声窗口 [-20,-10) ns；搜索 [0,2000) ns；最小门限 2 个码 |
| 测距 | 单峰邻域重心，前12/后24箱；固定 2 ns 延迟校正，不用几何真值拟合 |
| RGB | 640×360、16 spp、路径深度4；水平视场90°，fx=fy=320，cx=320，cy=180 |
| RGB 显示 | exposure=1，逐通道 Reinhard 后转 sRGB；另存原始线性 PFM |

RGB 使用 MTL Kd 漫反射预览，未分配的面显式使用灰色0.5；树木缺颜色时保持
解码的黑色，不擅自补成绿色。日光及环境光是实验假设，见 Render.cpp。
RGB 与近红外材质独立，不以 RGB 颜色反推905 nm反射率。

## 实际结果

聚合记录见 [RESULTS.json](RESULTS.json)，不是对所有场景的准确率保证。

| 统计 | 数值 |
| --- | ---: |
| 发射次数 / MC 射线数 | 11,520 / 184,320 |
| 输出测距点 | **9,613**（83.446% 的脉冲） |
| 全部光束样本未命中 | 1,373 |
| 有命中但无正回波样本 | 356 |
| 有正回波但未输出测距点 | 178 |
| ADC 越界脉冲 | 0 |
| 测得距离范围 | 4.25571–113.42118 m |
| 中心射线未命中但光斑输出点 | 6 |
| 落入前向 RGB 视野 | 2,198 |
| 展示叠加点 | 2,188 |
| 独立重投影最大差 | 约 1.35e-5 像素 |

`1373 + 356 + 178 + 9613 = 11520`，各组互斥；不是把天空漏测当作算法失败。
不同表面朝向、遮挡及接收/门限条件会使几何命中不产生数字测距点。
6个无中心命中的点不自动视为假点：有限发散光斑中的偏轴射线可以命中物体。

输出距离与中心几何射线距离的绝对差：中位数约0.005868 m，P95约0.033924 m，
最大23.201429 m。这里 P95 用 NumPy 线性分位数；C++ summary 使用离散索引，
会给出约0.033888 m。**这些不是纯测距误差指标**：边界光斑可能同时看到不同距离，
接收峰可能不对应中心射线。不能把中位数称作整个传感器精度。

点云是从数字波形估计距离生成，不是将几何交点作为测量答案。
`intensity` 是扣基线 ADC 幅值码，不是反射率，也不是经过真实仪器标定的强度。
点云叠加只展示满足 `abs(range-centerRange)<=max(0.15 m,0.002*range)` 的点；
该筛选仅影响图示，**不修改输出 PCD**。RGB 仅有前向90°，PCD包含完整360°。

## 材质与接触范围

- 使用可选 HELIOS 经验角度响应：1 个材料表条目解析 asphalt 光谱，76 个条目
  缺原始光谱而显式采用假设 rho=0.5；无 usemtl 的面另有显式经验 fallback。
  77是解析表条目数，不是77种独立测量材料，也不是整个 ECOSTRESS 自动映射。
- 9辆车的轮胎采样顶点与11棵树基准查询真实 Terrain BVH后，仅整体竖直升降。
  这是采样接触约束，不是悬架、四轮同时贴地或刚体动力学。
  旧 `SourcePlane` 模式仍为默认，不与本次新输出混用。
- 本次未开启大气、植被透射、接收电压噪声、多次散射或移动平台。
  光谱/微表面/涂层模型已有独立验收，不意味着 Urban 已自动获得完整物理材质。

## 本地输出与公开范围

默认 `out/UrbanSensorCheckpoint/run-*`，Git忽略：

- `scan/`：world/sensor PCD、逐脉冲日志、材质来源、放置报告、全景距离图与点云图。
- `rgb/`：RGB PNG/PPM、线性PFM、点云叠加、相机内外参及逐点投影诊断。
- `urban_checkpoint.png`：视觉与环绕扫描总览。
- `metrics.json`：独立核对后的聚合数字；`source-hashes.json`：运行源文件版本证据。
- 根目录构建、运行和Python验证日志；`build/`仅为本地独立实验程序。

公开仓库保存复现源码、固定参数、聚合报告与哈希；不上传原始Urban模型、
下载光谱、场景图像或点云衍生数据，因为独立资产及测量数据的再发布许可尚未确认。
不能把项目自身许可证当作这些外部素材的统一授权。
